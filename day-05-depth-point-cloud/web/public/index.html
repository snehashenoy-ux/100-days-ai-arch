1 · Depth from one photo

Depth Anything V2 (Metric-Outdoor-Small) estimates how far every pixel is, in metres. It's a 25M-parameter vision transformer running here through ONNX Runtime Web.

2 · Pixels to 3D

A pinhole camera model lifts each pixel into space: x = (u − W/2)·z/f, with f = (W/2)/tan(FOV/2).

3 · Into Rhino

The .ply is in metres and Z-up. In Rhino choose File → Import. It's a shell, because the camera only saw the fronts of things.
